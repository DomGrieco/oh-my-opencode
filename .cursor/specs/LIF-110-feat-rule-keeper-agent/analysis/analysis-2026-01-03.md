### Unique Innovations (Keep These!)

The spec proposes several patterns **not found in industry examples**:

1. **Evidence-based proposals** - Cite file:line for every pattern
2. **Anti-bloat guardrails** - Configurable line limits per tier
3. **Tier detection heuristics** - Auto-classify based on complexity
4. **Pattern occurrence threshold** - Only document 3+ occurrences
5. **Incremental updates** - Never regenerate entire files

These are **innovative and should be preserved**.
